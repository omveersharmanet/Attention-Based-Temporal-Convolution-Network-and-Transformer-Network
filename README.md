# Multi-Lane Highway Trajectory Prediction Using Attention-Based Temporal Convolution and Transformer Network
This work presents a novel combined driving behavior and trajectory predictor that integrates a multi-head attention mechanism (MHA) and a Temporal Convolution Network (ATCN) with a Transformer (TF)-based decoder to capture temporal correlations, complex non-linear relationships, and spatial-temporal dependencies among traffic participants. The model attains an RMSE of 1.96m on NGSIM and 1.11m on highD, outperforming existing methods.
